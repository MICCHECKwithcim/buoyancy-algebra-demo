### 🧭 Overview
This repository demonstrates a **symbolic, finite-step algorithm** for transforming harsh or absolute language into balanced, evidence-based statements.  
The process is called **Buoyancy Repair**, and it measures linguistic “pressure” using the Π (Pi) metric:

> Π = harm / (1 + provocation)

Lower Π means calmer, more proportional language.
